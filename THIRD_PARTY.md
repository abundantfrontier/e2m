# Third-party material

The E2M code, reports and results in this repository are Apache-2.0
(see `LICENSE` and `NOTICE`). The items below come from other projects and
keep their own licenses.

## Evaluation tasks shipped in this repository

| Source | Used for | License | Where |
|---|---|---|---|
| [HumanEval](https://github.com/openai/human-eval) (Chen et al., 2021, OpenAI) | 55 of the 78 held-out tasks were rewritten from HumanEval problems as leaf C functions with an English spec, a SysV signature, a C reference and tests | MIT, Copyright (c) OpenAI | `eval/heldout.jsonl`, `eval/heldout_visible.json`, per-task results under `results/` |
| [MBPP](https://github.com/google-research/google-research/tree/master/mbpp) (Austin et al., 2021, Google) | 23 of the 78 held-out tasks were rewritten the same way | CC BY 4.0 | same files as above |

The held-out tasks are adaptations: the English text, C signatures, C
references and test values were written for this project from the original
problems. Credit for the problems belongs to the original authors.

## Training-task sources (not redistributed here)

| Source | Used for | License |
|---|---|---|
| [ExeBench](https://huggingface.co/datasets/jordiae/exebench) `train_real_simple_io` (Armengol-Estapé et al., 2022) | the scaled training and validation task pool (`tasks/scaled.jsonl`, regenerated by `python -m e2m.scale`) | ExeBench contributions (I/O examples, boilerplate) are MIT; each C function keeps the license of its original GitHub repository (listed in the ExeBench metadata) |
| [AnghaBench](https://github.com/brenocfg/AnghaBench) (small sample) | a few hundred extra candidate functions for the same pool | per-file licenses of the original projects |

Validation task ids in `eval/val_split.json` refer to that pool; the pool
itself, the compiled variants and the SFT/DPO training files are not in this
repository (see `docs/DATA.md` to rebuild them).
